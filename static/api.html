KAMA AI 5.0 REST API

KAMA AI 5.0, Açık Kaynak Türkçe RoBERTa (BERTurk) mimarisi üzerine kurulu yüksek performanslı bilişsel analiz, argo/küfür kalkanı, yapay zeka diplomatı ve KVKK veri gizliliği servisidir.

Base URL

https://ai.oedge.xyz

Desteklenen Başlıklar (Headers)

Content-Type: application/json X-API-Key: YOUR_API_KEY (Opsiyonel / Yüksek hacimli çağrılar için)

Ana Hibrit Analiz Motoru

POST /kontrol

Metni RoBERTa modeli, argo ve sokak dili kalkanı, dikkat ısı haritası, duygu & ton analizi, AI diplomatı ve güvenlik kalkanlarıyla birlikte tam kapsamlı analiz eder.

İstek Parametreleri (Body JSON):

ParametreTipZorunlu mu?Açıklama
mesajstringEvetAnaliz edilecek Türkçe veya İngilizce metin.
dilstringHayırVarsayılan tr (Otomatik algılama desteklenir).

Örnek İstek (cURL):

curl -X POST "https://ai.oedge.xyz/kontrol" \ -H "Content-Type: application/json" \ -d '{"mesaj": "işler nasıl trrek"}'

AI Diplomat 5.0 (3 Tonlu Yeniden Yazıcı)

POST /api/v2/diplomat

Sert, kaba veya argo ifadeleri anlamını koruyarak 3 farklı hedef tona dönüştürür (Kurumsal, Dostane, Çocuk).

curl -X POST "https://ai.oedge.xyz/api/v2/diplomat" \ -H "Content-Type: application/json" \ -d '{"text": "çabuk yap lan şu işi bıktım senden gerizekalı"}'

KVKK / PII Veri Maskeleme

POST /api/v2/pii-mask

T.C. Kimlik, IBAN, Kredi Kartı, Telefon ve E-posta verilerini algoritmik olarak doğrular ve sansürler.

curl -X POST "https://ai.oedge.xyz/api/v2/pii-mask" \ -H "Content-Type: application/json" \ -d '{"text": "TC: 10000000146, IBAN: TR330006100519786457841324"}'

Phishing & E-Posta Güvenlik Kalkanı

POST /api/v2/phishing-check

Oltalama saldırılarını, aciliyet tetikleyicilerini ve şüpheli linkleri analiz eder.

curl -X POST "https://ai.oedge.xyz/api/v2/phishing-check" \ -H "Content-Type: application/json" \ -d '{"text": "Hesabınız askıya alındı, 24 saat içinde http://e-devlet-onay.tk adresine girin."}'
